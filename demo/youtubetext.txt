Send Notes to Project is a Paratext tool for consultants. A consultant often writes notes in a consultant notes project. With this tool you tick the notes you want the team to see, choose which comment of each note to send, and send them as new notes to the team's project, at the same verses. The note you sent from gets "Sent to ...", so you can see what you already sent. It works one chapter, or one verse, at a time. Start it from the project that will receive the notes, not from the consultant notes project.

Download Install_Phils_tools.exe from the Paratext Plugins folder, and tick Send Notes to Project in it:
