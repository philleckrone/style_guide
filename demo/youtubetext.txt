Biblica's style guides are a series of English guides that Biblica uses to help translation teams set out the standards for their project: punctuation, footnotes, headings, hyphenation, lists, numbers, poetry, quotations, syntax, and more. Each module is a Word document with a table of questions, NIV's practice, and a yellow cell for the team's own answer. Style Guide is a Paratext tool that reads your project and fills in those answers for you: it surveys the text, suggests an answer for each question, and shows the places it found. The team reviews or edits each answer, and then exports the module to Word with the yellow cells filled in. The answers are saved in the project's local folder only.
